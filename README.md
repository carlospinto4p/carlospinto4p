### Tyfold

I'm the author of [Tyfold](https://tyfold.com/?utm_source=github&utm_medium=post&utm_campaign=github-personal-profile), a desktop IDE with the terminal in the middle. It's for developers who spend the day directing Claude Code, Codex, opencode, and potentially any other TUI I might support in the future. It is focused on agents: links to files in the chat can be opened in a built-in file browser, there is a custom queue for pending prompts, support for worktrees, an integrated tool for drawing interactive graphs and diagrams -that agents can use natively-, and a widget mode to keep session statuses always on screen.

Give it a try. I built it because I wanted to have this tool for my own development processes.
