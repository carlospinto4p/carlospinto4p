### Tyfold

I'm building [Tyfold](https://tyfold.com/?utm_source=github&utm_medium=post&utm_campaign=github-personal-profile),
a desktop IDE with the terminal in the middle. Your agents, your build and
your ssh logins run there, and files, diffs and search are reached from it.
It's for developers who spend the day directing Claude Code, Codex or opencode.

Tyfold is closed source, so its code isn't on GitHub. The releases are at
[tyfold/downloads](https://github.com/tyfold/downloads), and questions and bug
reports go to its [Discussions](https://github.com/tyfold/downloads/discussions).
